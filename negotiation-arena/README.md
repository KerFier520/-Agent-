# Negotiation Arena

**跨文化商业谈判的多 Agent 对抗模拟系统**

> 把 AI 从"回答问题的助手"变成"拥有独立目标、私有信息和适应性策略的虚拟商业对手"。

---

## 一句话介绍

Negotiation Arena 是一个交互式跨境商业谈判平台。你扮演中国电子制造企业的海外业务负责人，与一个**目标独立、信息不对称、策略会随你调整**的 AI 采购商谈判。系统同时运行企业财务负责人（内部硬约束）、跨文化顾问（沟通策略分析）和谈判裁判（结构化复盘）三个辅助 Agent，构成一个真正的多主体博弈环境，而不是角色扮演聊天。

对应框架：**① 金融经贸 + ④ AI 陪伴交互 + ⑤ 湾区出海创新**

---

## 为什么这不是"角色扮演聊天"

| 维度 | 普通角色扮演 | Negotiation Arena |
|---|---|---|
| 对手目标 | 配合用户推进剧情 | 独立效用函数，接受与否由数值决定 |
| 信息结构 | 全知或无状态 | 买方的保留价、锁量窗口、BATNA 全程隐藏，仅复盘揭示 |
| 状态 | 无持久状态 | 条款 / 信任 / 张力 / 阶段 FSM 逐轮演化并可存档 |
| 策略 | 按 prompt 生成 | 读取你的让步速率与强硬度，动态调整让步步长与接受阈值 |
| 内部约束 | 无 | 财务 Agent 对毛利率、信用敞口拥有**硬否决权** |
| 复盘 | 泛泛总结 | 五维评分 + 转折点识别 + 反事实推演 |
| 可逆性 | 不可逆 | 时间回溯到任一节点重新决策，隐藏状态同步回滚 |

## 核心机制

### 1. 隐藏信息（不可全知全能）

买方的私有状态封装在 `state._private` 中，`publicState()` 对外过滤，包括快照内部数据：

```js
priv = {
  reservePrice,    // 她能接受的最高单价
  targetPrice,     // 内部目标价
  minVolume,       // 必须拿下的铺货量
  channelCap,      // 渠道消化上限
  cashCycleNeed,   // 现金周期决定的账期硬需求
  deadlineRound,   // 旺季锁量窗口（时间压力来源）
  batnaUtility     // 备选供应商的价值
}
```

这些值**只在裁判复盘时揭示**。测试用例 `3. 隐藏信息` 对序列化输出做字符串级断言，确保不泄露。

### 2. 状态演化（有限状态机）

```
opening ──> exploring ──> bargaining ──> endgame ──> closed
 开场定调     探询试探       实质议价       终局收口      已结束
```

每轮提交会同时推进：可谈判条款 `terms`、关系仪表 `meters{trust, tension}`、阶段 FSM、买方记忆 `buyerMemory`。阶段影响买方的时间压力系数，进而影响她的期望衰减率。

### 3. 策略适应（AI 读对手模式）

买方维护一个对手模型：

```js
buyerMemory = {
  avgConcession,  // 你平均每轮让出多少（买方效用口径）
  adaptation,     // -1 很软 … +1 很硬
  trustBias,      // 关系溢价
  disclosed       // 她已经向你透露了哪些底牌
}
```

- 你让得越快 → 她**更有耐心**，期望值衰减变慢，最终压价更狠
- 你立场坚定 → 她的期望加速衰减，提前进入收敛
- 信任 < 35 → 她的让步步长主动收缩 30%

模拟验证（`test/balance.sim.js`，5 局 × 4 策略）：

| 策略 | 成交率 | 平均年毛利 | 平均得分 |
|---|---|---|---|
| 探询后收口 | 5/5 | **165.8 万美元** | 68 |
| 稳健让步 | 5/5 | 143.0 万美元 | **80** |
| 快速投降 | 5/5 | 87.3 万美元 | 58 |
| 硬派不让 | 0/5 | — | — |

「快速投降」能成交但毛利腰斩，「硬派不让」一局都谈不成 —— 博弈是真实的。

### 4. 内部约束 Agent（财务负责人）

财务负责人不是旁白，而是**提交前的硬关卡**。违反以下任一条，报价根本发不出去：

- 毛利率 < 12%
- 年度承诺量 < 8 万台（产线排期不经济）
- 账期 > 60 天且预付 < 15%
- 滚动信用敞口 > 300 万美元授信上限
- 给区域独家但量 < 18 万台

这让"向对方让步"与"说服内部"成为两个必须同时满足的约束，而不是单向妥协。

### 5. 时间回溯（反事实实验）

每轮自动快照完整状态（含买方隐藏信息与记忆）。点击任一节点可回溯：

- 回合数、仪表、对话记录、对手记忆**同步回滚**
- 被放弃的路径保留为 `branches` 平行线记录
- 随机数由 `seed + 游标` 重建，**重放同一动作结果完全一致**（已测试）

这使"如果当时不施压会怎样"成为可实验的问题，而不是口头假设。

### 6. 结构化评估（谈判裁判）

五维加权评分 + 转折点识别 + 每个转折点的反事实推演：

```
总分 = 利润 34% + 风险 20% + 协议质量 20% + 关系 16% + 效率 10%
```

转折点按"单轮买方效用变化 + 信任变化"的幅度排序，并标注是「有效步」还是「代价步」。

## 关于文化差异的处理（重要设计决策）

**本系统不把文化差异编码为国籍刻板印象。**

对手 Daniela Roth 的行为由**可验证的组织处境**驱动，而非她来自哪个国家：

- 采购流程要求三家比价，让步必须落到书面条款清单（口头承诺不进审批流）
- 个人签批权限 300 万美元，超出需等月度董事会例会
- 上财年因缺货错过旺季，KPI 新增"交付确定性"
- 团队习惯先谈商务框架再谈技术细节

这些设定全部**可在谈判中被验证或证伪**：你通过探询可以确认她的签批线，可以观察她是否真的对书面材料更买账。

系统另有 4 种**谈判画像**（流程导向 / 压价导向 / 交付优先 / 长期合作），每局随机抽取并影响她的耐心、让步率、抗压性。跨文化顾问 Agent 只从**已观察到的行为**推断画像，并明确声明"这是从她的行为推断的，不是从她来自哪个国家推断的；若后续观察与此矛盾，以行为为准"。

测试用例 `12. 文化建模` 对人物设定做国籍标签的负向断言。

## 作为库使用

```js
const Arena = require('./src/engine/arena.js');

const game = Arena.createGame({ seed: 'demo-001' });

const res = Arena.submitOffer(game, {
  terms: { price: 23.5, qty: 20, depositPct: 20,
           netDays: 45, warrantyMonths: 12, exclusivity: false },
  move: 'tradeoff',                       // 沟通策略
  note: '量到 22 万台我可以在账期上再让 15 天。'
});

if (!res.ok && res.blockedBy === 'cfo') {
  console.log('财务否决：', res.message);  // 报价根本发不出去
} else {
  console.log('她的回应：', res.speech);
  console.log('她的还价：', res.counter);
  console.log('顾问提示：', res.advisor);
}

// 时间回溯
Arena.rewind(game, game.snapshots[2].id);

// 持久化
const saved = Arena.save(game);
const resumed = Arena.load(saved);
```

### 七种沟通策略

| 动作 | 效果 |
|---|---|
| `structured` | 结构化条款说明 — 匹配她的书面化审批流程，信任与可信度双增 |
| `rapport` | 关系铺垫 — 大幅降张力，可能换到她的 KPI 底牌 |
| `probe` | 提问探询 — 用一轮时间换隐藏信息 |
| `tradeoff` | 条件交换 — if-then 绑定对等让步，可信度最高 |
| `pressure` | 施压 — 短期压缩对方预期，消耗信任 |
| `ultimatum` | 最后通牒 — 第 5 轮前使用会触发流程性反弹，让步步长压到 35% |
| `walkaway` | 表示终止 — 可能逼出底牌，也可能真的谈崩 |

## 技术实现要点

- **多 Agent 编排**：四个 Agent 共享一个状态树，但读写权限不同 —— 买方只能读 `_private.buyer`，顾问只能读已观察行为，裁判在终局读全量
- **有限状态机**：阶段转换由回合数与状态共同决定，并反作用于买方的时间压力系数
- **博弈机制**：双方各自的效用函数 + BATNA + 保留价 + 期望衰减，构成可分析的议价模型
- **长期状态存储**：`save()` / `load()` 完整序列化（含隐藏信息与 RNG 游标），载入后可继续推进与回溯
- **可复现性**：所有随机性来自 `seed + 游标`，同 seed 同动作必得同结果 —— 这是时间回溯能做反事实对比的前提
- **结构化结果评估**：五维评分、转折点排序、反事实生成
